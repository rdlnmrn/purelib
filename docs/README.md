# Documentation

The [repository README](../README.md) introduces the library, papers and
Lean facades. Contributor conventions are in [AGENTS.md](../AGENTS.md).

## Guides

- [Completion checks](verification.md): Run the full build, tooling, lint and proof checks, with reusable caches and stage timings.
- [Lean linting](linting.md): Selected checks, constructive exclusions and contributor commands.
- [Compiled declaration tracing](compiled-tracing.md): Investigate proof dependencies and compare compiled declaration types.
- [Constructor certificates](constructor-certificates.md): Use metadata-derived injectivity proofs and understand their verification scope.
- [Profiling](profiling.md): Recognize and repair expensive Lean compilation and computation.
- [Certified restarting](certified-restarting.md): Retain ownership and validate checkpoints when resuming computations.
- [Interactive CCL introduction](ccl/README.md): Build and serve the visual essay locally.
